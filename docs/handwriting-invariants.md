# الثوابت الإلزامية لمنظومة الكتابة اليدوية (Handwriting System Invariants)
**تطبيق دَارُ الحِكَايَاتِ (Dar Al Hikayat)**

## 1. تاريخ الإصلاحات والسبب الجذري لمشكلة "الرسم لا يظهر"
تمت مراجعة سجلات الكود التاريخية بدقة لتحديد أسباب المشكلة السابقة وثوابت عدم العودة إليها:

1. **الكوميت `d7c9b84` — ربط مقاس الـ Canvas بـ Node الفعلي:**
   - *السبب الجذري:* كان الـ Canvas يعود للحجم الافتراضي لـ HTML (300×150) في حال لم يتم قياس وتحديث الحجم الفعلي بعد التركيب (Mount)، مما جعل الإحداثيات تنحرف كلياً ولا يظهر الرسم في المكان المطلوب.
   - *الثابت:* الحفاظ على `canvasNode` state وتحديث مقاسات اللوحة بدقة وربط الـ Viewport والـ DPR فور التركيب.

2. **الكوميت `518c59f` — قفل التمرير وحماية أحداث اللمس:**
   - *السبب الجذري:* متصفحات الأندرويد والـ WebView كانت تبتلع أحداث اللمس كإيماءات تمرير للصفحة (Scroll gestures)، مما يمنع وصول إحداثيات الرسم تماماً.
   - *الثابت:* قفل التمرير `document.body.style.overflow = "hidden"` و`touch-action: none` واستدعاء `e.preventDefault()` على كل أحداث اللمس غير الملغاة.

3. **الكوميت `5113c86` و`acf2221` — إدارة أحداث المؤشر على مستوى النافذة (Window-Level Listeners):**
   - *السبب الجذري:* عند حركة اليد السريعة، كانت إحداثيات المؤشر تخرج خارج حدود اللوحة لجزء من الثانية فتنقطع المسارات أو تفقد نهاياتها.
   - *الثابت:* الاستماع لأحداث `pointermove` و`pointerup` و`pointercancel` على مستوى `window` مع ربط `pointerdown` باللوحة.

4. **الكوميت `53999ab` — الممحاة الجزئية الدقيقة للمسارات المتجهية:**
   - *السبب الجذري:* كانت الممحاة البدائية تحذف المسار كاملاً أو تطلي باللون الأبيض، مما يفسد التراجع والشفافية.
   - *الثابت:* استخدام خوارزمية تقاطع الدائرة مع أضلاع المسار وحساب نقاط الدخول والخروج مع تقليم الشظايا متناهية الصغر (Specks).

5. **الكوميت `4ed3cbb` — التخزين المتجهي الصريح وفصل المعاينة:**
   - *السبب الجذري:* توليد صور PNG بشكل غير متزامن كان يتسبب في تلوث المسارات المحفوظة أو إرجاع لوحة فارغة.
   - *الثابت:* الحفظ يعتمد حصرياً على المتجهات `Stroke[]` وتوليد المعاينة بصيغة SVG/Geometry نظيفة.

## 2. الثوابت المعمارية الحاكمة للمسار الحي (Hot Path Invariants)
- **ممنوع React State أثناء الرسم:** يتم التحديث أثناء حركة القلم مباشرة على الـ Canvas عبر الـ Refs و`CanvasRenderingContext2D`.
- **أول بكسل فوري:** النقطة الأولى عند `pointerdown` ترسم متزامنة فوراً دون انتظار rAF.
- **تطابق الرسم الحي والنهائي:** الخوارزمية المستخدمة أثناء السحب هي نفسها المستخدمة عند التثبيت لضمان عدم وجود "قفزة" شكلية عند رفع القلم.
- **عزل الذكاء الاصطناعي:** التعرف على الأشكال لا يُستدعى في كل نقطة؛ لا يُسمح بالتحويل إلا بعد إكمال التوقف المطلوب قبل رفع القلم.
