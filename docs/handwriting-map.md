# خريطة منظومة الكتابة اليدوية (Handwriting System Map)
**تطبيق دَارُ الحِكَايَاتِ (Dar Al Hikayat) — v3.0.0**

## 1. الهيكل والملفات المكوّنة للمنظومة
- `components/DarAlHikayatHandwriting.tsx`: المكوّن البصري والتفاعلي الرئيسي لإدارة اللوحة والأدوات وأحداث اللمس والـ Portal.
- `components/HandwritingPreview.tsx`: مكوّن عرض المعاينة السريعة للمسارات المتجهية في بطاقات الشاشة الرئيسية (Home Cards).
- `lib/handwriting-document.ts`: معالجة نموذج البيانات المتجهي، التحقق من وجود الحبر، وتوليد هندسة المعاينة (Geometry & SVG paths).
- `lib/handwriting-eraser.ts`: خوارزمية المسح الجزئي الدقيق (Vector Path Trimming / Segment-Circle intersection).
- `lib/handwriting-engine.ts`: محرك التنعيم وحساب السماكة التفاعلية والسرعة ومنحنيات Bezier وخطوط اليد الاحترافية.
- `lib/handwriting-eraser-dual.ts`: المنظومة المزدوجة للممحاة (الممحاة الجزئية المقسمة للمسارات + الممحاة الكائنية للمسار الكامل).
- `lib/handwriting-highlighter.ts`: محرك التظليل الاحترافي بدمج الألوان والشفافية وحظر كبسولات النظام.
- `lib/handwriting-lasso.ts`: خوارزمية التحديد باللاسو والتحويل المتناسب والتحريك.
- `lib/handwriting-shapes.ts`: مصنف الأشكال الذكي (Hold-to-Shape) مع حماية الحروف والأرقام العربية.
- `lib/handwriting-feature-flags.ts`: مفاتيح الإيقاف والتشغيل الثابتة في الكود للتراجع الفوري.

## 2. تدفق البيانات من حدث اللمس حتى ظهور البكسل (The Hot Path)
1. **أحداث المؤشر (Pointer Events):**
   - يدعم اللمس بالإصبع، قلم Stylus (S-Pen / Apple Pencil)، والماوس.
   - منع السلوك الافتراضي لمتصفح الويب (`preventDefault()`, `touch-action: none`).
   - استخراج إحداثيات العالم الحقيقي (World Coordinates) بأخذ موضع الـ Canvas وإزاحة التمرير اللانهائي `panY`:
     `worldX = clientX - rect.left`
     `worldY = clientY - rect.top + panY`
2. **أول لمسة (pointerdown):**
   - رسم فوري للبكسل الأول مباشرة على الـ Context بسياق Canvas دون أي انتظار لـ rAF أو تحديث React State.
   - تسجيل نقطة البداية `StrokePoint { x, y, pressure, time }`.
3. **حركة المؤشر (pointermove):**
   - استدعاء `getCoalescedEvents` للحصول على كل النقاط الدقيقة حتى في الشاشات بتردد 120Hz.
   - حساب منحنيات Bezier الملساء والسماكة المتجاوبة مع سرعة القلم.
   - الرسم التزايدي المباشر على سياق اللوحة.
4. **رفع القلم (pointerup):**
   - تثبيت المسار المكتمل بنفس الخوارزمية البصرية لمنع أي قفزة بصرية.
   - تفعيل مصنف الأشكال (إذا تحققت شروط الإمساك بالتوقف المؤقت).
   - تسجيل الحالة في سجل التراجع/الإعادة (Undo/Redo History).
   - إخطار المكون الأب بالتغيير لتفعيل مؤشر التعديلات غير المحفوظة.

## 3. إعداد الـ Canvas والطبقات
- **DPR Scaling:** استخدام `dpr = Math.min(window.devicePixelRatio || 1, 2)` لضمان الدقة العالية مع ترشيد استهلاك الذاكرة.
- **طبقة التسطير (Ruled Lines Canvas):** في الخلفية، تُحدَّث فقط عند التمرير أو تغيير خيار التسطير.
- **طبقة الحبر الرئيسية (Main Inking Canvas):** تحمل المسارات المتجهية الحية والمثبتة.
- **طبقة التحديد واللاسو (Lasso Overlay):** ترسم حلقة التحديد ومقابض التحويل عند تفعيل أداة اللاسو.

## 4. نموذج البيانات والتوافق الخلفي
- تخزين متجهي 100% (Vector Strokes).
- كل مسار يتكون من: `id`, `color`, `width`, `points: [{ x, y, pressure, time }]`.
- الحقول الجديدة (مثل `tool`, `opacity`, `shapeType`) اختيارية تماماً، مما يضمن فتح وقراءة أي مسارات قديمة بنسبة 100% دون أي تحويل مدمّر.
